# CS 320 Software Testing, Automation, and Quality Assurance

## About This Repository

This repository contains work that I completed during my CS 320 Software Testing, Automation, and Quality Assurance course at Southern New Hampshire University. Throughout this course, I learned more about the importance of software testing and how developers can use different testing methods to make sure their programs work correctly and meet user requirements.

For Project One, I developed a contact service application and created JUnit tests to verify that the application worked as expected. For Project Two, I completed a summary and reflections report discussing my testing approach, the techniques I used, and what I learned throughout the course.

The files included in this repository demonstrate my understanding of software development, unit testing, and quality assurance.

## Reflection

### How can I ensure that my code, program, or software is functional and secure?

I think one of the most important ways to make sure software is functional and secure is through proper testing. Throughout this course, I learned how important it is to test different parts of a program instead of assuming everything works because the code runs. When developing my contact service, I used JUnit testing to verify that the program followed the requirements and handled invalid inputs correctly. For example, I tested the restrictions on contact IDs, names, and phone numbers to make sure invalid information could not be accepted.

I also think security needs to be considered throughout the entire development process. Validating user inputs, protecting sensitive information, and keeping code organized can help prevent problems before software is released. Testing is not going to catch every possible issue, but it helps reduce the chances of errors making it into the final product.

### How do I interpret user needs and incorporate them into a program?

When interpreting user needs, I think it is important to understand exactly what the user expects the software to accomplish before starting development. If the requirements are unclear, developers can end up creating something that works but does not actually meet the user's expectations.

During this course, I worked with specific requirements for the contact service, including how contacts should be created, updated, and deleted. I used these requirements to determine how the program should function and what needed to be tested. I also learned that breaking down requirements into smaller tasks makes development easier to manage. This is something I can apply to future projects and in my work as an IT Specialist because understanding what someone actually needs is an important part of solving technical problems.

### How do I approach designing software?

When designing software, I prefer to start by understanding the requirements and planning how the different parts of the program will work together. I think having a clear plan before writing code helps prevent unnecessary problems later in development.

For my contact service project, I separated the contact information from the service responsible for managing contacts. This made the code easier to organize, maintain, and test. I also created unit tests to make sure each part of the program behaved correctly.

One thing I have learned throughout my computer science courses is that software development is not just about getting a program to run. It is also about creating something that can be maintained, improved, and tested as requirements change. Moving forward, I want to continue improving my ability to design software that is reliable, efficient, and easy to work with.

## Conclusion

Overall, CS 320 helped me better understand how important testing is throughout the software development process. Before this course, I mainly focused on making sure my code worked when I ran it. Now I have a better understanding of why developers need to test different situations, including invalid inputs and unexpected behavior.

I plan to take what I learned from these projects and apply it to future software development work. Having a strong understanding of testing and quality assurance will help me create better programs and become a more effective software developer.
